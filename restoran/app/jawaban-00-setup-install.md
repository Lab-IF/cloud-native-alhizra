## 📝 Kuis Singkat

### 1. Versi Node.js minimum yang dibutuhkan untuk Next.js adalah...

**Jawaban:** Minimal Node.js v18.17.0 atau yang lebih baru. Sangat disarankan menggunakan versi LTS (Long Term Support) agar lingkungan pengembangan kamu lebih stabil.

### 2. Saat create-next-app, untuk menggunakan JavaScript kita pilih TypeScript = ...

**Jawaban:** No.
Saat menjalankan perintah npx create-next-app@latest, sistem akan bertanya "Would you like to use TypeScript?". Untuk menggunakan JavaScript, kamu harus menekan tombol panah atau mengetik No.

### 3. File konfigurasi yang muncul saat memilih JavaScript (bukan TypeScript) adalah...

**Jawaban:** jsconfig.json.
Jika kamu menggunakan TypeScript, file yang muncul adalah tsconfig.json. File ini berfungsi untuk membantu editor (seperti VS Code) memahami struktur proyek dan memberikan fitur auto-complete kode.
